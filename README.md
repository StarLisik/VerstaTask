# VestaTask

Веб-приложение на ASP.NET Core MVC (.NET 9) для приемки заказа на доставку. Данные хранятся в SQLite через EF Core.

## Стек

- ASP.NET Core MVC, .NET 9
- Entity Framework Core 9 + SQLite

## Требования

- [.NET SDK 9.0](https://dotnet.microsoft.com/download) или новее

## Запуск проекта

1. Склонируйте репозиторий и перейдите в папку проекта.

2. Сделайте build приложения:
   ```bash
   dotnet build
   ```

   База данных SQLite (`DBs/Orders.db`) создаётся автоматически при первом запуске - при старте применяются миграции EF Core.

3. Должен открыть браузер с запущенным приложением

## Функциональность

- **Создание заказа** (`/Home/Create`) — форма создания заказа.
- **Список заказов** (`/Home/AllOrders`) — таблица всех оформленных заказов.
- **Просмотр заказа по Id** (`/Home/GetOrderById?id=...`) — информация по конкретному заказу. При отсутствии заказа возвращается 404.
